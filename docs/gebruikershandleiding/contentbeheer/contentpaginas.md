# Contentpagina's

Via **Content** in de Balie kun je de vaste pagina's en teksten van het platform aanpassen.

In het overzicht zie je per contentpagina de titel en de knop **Bewerken**. De volgende contentpagina's zijn beschikbaar:

| Titel                                         | Waar wordt de inhoud getoond                                                                  |
|-----------------------------------------------|-----------------------------------------------------------------------------------------------|
| **Contact** (Balie)                           | De contactpagina in de Balie (**/balie/contact**), te bereiken via de footer van de Balie.    |
| **Contact**                                   | De contactpagina op de publieke website (**/contact**), te bereiken via de footer.            |
| **Cookies**                                   | De cookiepagina op de publieke website (**/cookies**).                                        |
| **Copyright**                                 | De copyrightpagina op de publieke website (**/copyright**).                                   |
| **Andere publicaties**                        | Het blok *Andere publicaties* op de homepage van de publieke website.                         |
| **Openbaar gemaakte informatie**              | De introductietekst bovenaan de homepage van de publieke website.                             |
| **Een Woo-verzoek indienen**                  | Het blok *Een Woo-verzoek indienen* op de homepage van de publieke website.                   |
| **Kwetsbaarheid melden**                      | De pagina voor het melden van een kwetsbaarheid (**/kwetsbaarheid-melden**).                  |
| **Over dit platform**                         | De pagina Over dit platform (**/over-dit-platform**), ook gelinkt vanaf de homepage.          |
| **Privacyverklaring Wet open overheid (Woo)** | De privacyverklaring op de publieke website (**/privacy**) en in de Balie.                    |
| **Toegankelijkheid**                          | De toegankelijkheidsverklaring op de publieke website (**/toegankelijkheid**) en in de Balie. |

Klik op **Bewerken** om de titel en de inhoud van een pagina aan te passen. Meer uitleg over het opmaken van de tekst vind
je in [Teksteditor](./teksteditor.md).
