# Actieve openbaarmaking

Deze werkwijze geldt voor alle publicatietypes, behalve het **Woo-besluit**. Het **Woo-besluit** heeft een eigen uploadstraat,
zie [**Woo-besluit**](../woo-besluit/index.md).

Om te kunnen publiceren heb je een account nodig met de rechten **publicatiebeheerder** in de Balie.

Als je inlogt in de Balie kom je terecht in het overzicht 'Alle publicaties'.
Om een nieuwe publicatie aan te maken, klik je rechtsboven op de knop **Nieuwe publicatie** en kies je het publicatietype. Het aanmaken van een publicatie bestaat uit drie stappen:

1. [Basisgegevens](stap1-basisgegevens.md) invullen;
2. [Details en documenten](stap2-details.md) toevoegen;
3. [De publicatiedatum](stap3-publiceren.md) instellen.

Een aantal velden verschilt per publicatietype. Die vind je op de pagina van het type onder [Publicatietypes](publicatietypes.md).

```{toctree}
:maxdepth: 1
:caption: Inhoudsopgave

stap2-details
stap3-publiceren
publicatietypes
```
